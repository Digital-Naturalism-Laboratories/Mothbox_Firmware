Identity

What this Mothbox calls itself in its data folders.

On: the Mothbox invents a unique name for itself. Off: it uses the name below.

Letters, numbers, hyphens and underscores only — it becomes part of folder names.

Time & place

The timezone must be one of the official names in timezone_list.txt.

Leave this on unless the Mothbox has no way to learn the time (no GPS, no network).

Applied once, then automatic time setting turns itself back on. Format: YYYY-MM-DD HH:MM:SS. The two extra minutes give you time to save this file and get the card into the Mothbox before that moment arrives.

Schedule

The Mothbox wakes on every selected day, at every selected hour, at the chosen minute.

A session that starts at hour H starts at H:00.

Advanced: several minutes per hour

Every minute here is combined with every hour above — minutes 0;30 with hours 19;21 gives four sessions: 19:00, 19:30, 21:00, 21:30.

How long the Mothbox stays awake taking photos each time. Keep it under 60 if you wake up hourly.

WiFi

A network the Mothbox should join when it is in a mode that turns WiFi on.

Stored as plain text in the CSV, exactly as it always has been. Leave the examples alone if you are not adding a network.

Battery

Used for the battery gauge and the low-power shutdown. Read these off the battery itself.

TalentCell PB1202B is 142 Wh. Only have amp-hours? Multiply Ah × volts.

Other settings in this file

Settings this editor does not have a special control for. They are kept exactly as they were unless you change them here.

Two things that break Mothboxes

      
    
        
  • Don’t open the CSV on the card with Excel, Numbers, Vim, Sublime or Notepad++. They leave swap files and backups on the tiny boot partition and rewrite the file with different encodings and line endings. Use this page instead.
    • 
        
  • Always eject the card properly and wait until the computer says it is safe before pulling it out. Yanking it mid-write corrupts the boot partition, and then the Pi just blinks at you.
